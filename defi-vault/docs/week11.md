# Неделя 11 — пулы ликвидности и ценовые диапазоны

## Обычный пул и CLMM

В обычном AMM (`x * y = k`) ликвидность размазана по всем ценам от 0 до бесконечности,
и большая её часть никогда не используется. В CLMM (Concentrated Liquidity Market Maker)
поставщик сам выбирает диапазон цен. Тот же капитал работает плотнее, поэтому
проскальзывание ниже, а доля комиссий выше. Плата за это — позиция зарабатывает, только
пока цена внутри диапазона.

## Основные понятия

| Понятие | Что значит |
|---|---|
| **Тик** | Шаг цены: `price = 1.0001^tick`. Один тик — это 0.01% |
| **Tick spacing** | Границы позиции ставятся только на кратные ему тики. Здесь 10 |
| **sqrtPriceX64** | Цена в пуле: `sqrt(price) * 2^64`. Удобно для целочисленной математики |
| **Ликвидность L** | Сколько токенов нужно на изменение цены: `Δy = L * Δsqrt(P)` |
| **Tick array** | Аккаунт на 60 инициализируемых тиков. При spacing 10 покрывает 600 тиков |
| **AmmConfig** | Настройки пула: комиссия и tick spacing. Здесь 0.05% и 10 |
| **token0 / token1** | Токены упорядочены: адрес token0 меньше адреса token1. Цена — token1 за token0 |

## Что лежит в позиции в зависимости от цены

| Цена | Состав позиции | Комиссии |
|---|---|---|
| Ниже диапазона | Только token0 | Не начисляются |
| Внутри диапазона | Оба токена | Начисляются |
| Выше диапазона | Только token1 | Не начисляются |

Поэтому при выходе цены из диапазона позицию нужно переставлять (неделя 13).

## Что сделано

`scripts/setup-pool.ts` создаёт два тестовых токена, CLMM-пул Raydium с ценой 1
и стартовую ликвидность в диапазоне тиков `[-1000, 1000]` (примерно ±10% от цены).
Результат сохраняется в `deployments/<cluster>.json`.

## Запуск

```bash
# devnet: нужен кошелёк с SOL
RPC_URL=https://api.devnet.solana.com yarn tsx scripts/setup-pool.ts

# локально, с настоящей программой Raydium, склонированной из devnet
scripts/start-validator.sh &
yarn tsx scripts/setup-pool.ts
anchor test --skip-local-validator
```

Тесты: `tests/week11-clmm-pool.ts`.
