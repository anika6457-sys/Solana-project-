# Неделя 13 — позиция в CLMM из vault

## Инструкции

| Инструкция | Что делает |
|---|---|
| `open_position` | Открывает позицию в выбранном диапазоне тиков. NFT позиции лежит у PDA vault |
| `collect_fees` | Выплачивает накопленные комиссии, ликвидность не меняется |
| `decrease_liquidity` | Выводит часть или всю ликвидность с защитой минимальными суммами |
| `close_position` | Закрывает пустую позицию, возвращает rent управляющему |
| `assert_out_of_range` | Завершается успешно, только если цена вне диапазона |
| `sync_total_assets` | Обновляет цену доли, когда все средства снова в основном токене |

## Зачем нужен lp_signer

Raydium берёт и токены, и rent у одного подписанта. PDA vault на эту роль не подходит:
в нём есть данные, а System Program не разрешает создавать аккаунты за счёт такого аккаунта.
Поэтому используется отдельный PDA `["lp_signer", vault]` без данных:

1. Vault выдаёт ему право (`approve`) на max-суммы токенов.
2. Управляющий переводит ему SOL на rent новых аккаунтов.
3. `lp_signer` подписывает CPI в Raydium.
4. Право отзывается (`revoke`), остаток SOL возвращается управляющему.

Доступ ограничен рамками одной инструкции, после неё у `lp_signer` нет ни SOL, ни прав.

## Перестановка при выходе цены из диапазона

`vaultRebalance` в `scripts/lib/vault.ts`:

```
assert_out_of_range + decrease_liquidity(вся ликвидность)  → токены и комиссии в vault
close_position                                             → rent обратно
swap(половина разницы, с минимумом)                        → оба токена поровну
open_position(новый диапазон вокруг текущей цены)
```

Всё в одну транзакцию не помещается (лимит 1232 байта), поэтому шаги идут отдельно.
Если шаг упал, средства остаются в vault, и перестановку можно продолжить.

## Цена доли

Без оракула стоимость второго токена надёжно не посчитать. Поэтому `total_assets` обновляется
только после полного возврата в основной токен: `sync_total_assets` требует, чтобы не было
открытой позиции, а на аккаунте второго токена было пусто. Прибыль или убыток делятся между
держателями долей пропорционально.

## Ограничения

- Управляющий (`authority`) сам решает, когда размещать средства и переставлять позицию.
  Пользователи ему доверяют. Защитное ограничение: средства могут идти только на аккаунты vault
  и только в заданный пул.
- Пока средства размещены, вывод ограничен свободным остатком в хранилище (`InsufficientIdleAssets`).
- Награды пула (rewards) не собираются, только комиссии.
