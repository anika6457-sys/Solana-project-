# Неделя 8 — каркас DeFi-vault

Vault принимает токены пользователей и позже размещает их в пуле ликвидности.
На этой неделе собран каркас из трёх частей.

| Аккаунт | Адрес (seeds) | Назначение |
|---|---|---|
| `VaultConfig` | `["vault", asset_mint]` | Настройки: кто управляет, какой токен принимается, общая сумма активов |
| Share-токен | `["share", vault]` | Доля пользователя. Выпускать его может только PDA vault |
| Хранилище | `["asset_vault", vault]` | Токен-аккаунт, в котором лежат средства. Владелец — PDA vault |
| `UserAccount` | `["user", vault, owner]` | PDA пользователя: сколько он внёс и вывел |

Инструкции: `initialize_vault`, `create_user_account`.

За основу взят стандартный шаблон `anchor init` (Anchor 1.x).

Тесты: `tests/week08-skeleton.ts`.
